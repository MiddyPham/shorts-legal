Privacy Policy

Last updated: November 2026

Shorts Factory is a private, single-user tool that the owner uses to publish their own original animated short videos to their own YouTube, TikTok and Instagram accounts.

YouTube API Services

Shorts Factory uses YouTube API Services to upload videos to, and read statistics of, the owner's own YouTube channels. By using Shorts Factory you agree to be bound by the YouTube Terms of Service. YouTube data is handled according to the Google Privacy Policy. Access granted to Shorts Factory can be revoked at any time via the Google security settings page.

Data we access

  • Basic profile information of the owner's connected accounts (account id, display name), used only to confirm the right account is connected.
  • Publishing permission, used only to upload videos the owner created.
  • Aggregate statistics of the owner's own videos (views, likes, comments, shares, watch time), used only to decide which content to make next.

Storage and sharing

Access tokens and statistics are stored only on the owner's computer. No data is sold, shared with third parties, or used for advertising. The tool does not access data of any other users.

Deletion

The owner can revoke access at any time from the platform's security settings (Google Account → Security → Third-party access; TikTok → Settings → Security → Manage app permissions; Instagram → Settings → Website permissions). Local data is deleted by removing the tool's folder.

Contact

Questions: contact the channel owner via the email listed on the channel.
